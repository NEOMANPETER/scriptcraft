# ScriptCraft

Open `index.html` in a browser. No install.

Keep these folders next to `index.html`:

- `fonts/` — Courier Prime. Without it the page falls back to a system monospace font.
- `icons/` — the ScriptCraft logo. Without it the corner mark and the browser icon do not show.

## Put it on GitHub

1. Upload this whole folder: `index.html`, `fonts/`, `icons/`, `favicon.png`, and this README.
2. If the site already has an older `index.html` or `scriptcraft.html`, replace that file with this `index.html` (rename it to match the old name if the live page is not called `index.html`).
3. Commit. GitHub Pages picks it up from the repo root.

Scripts stay in the browser. Nothing is sent to a server.
