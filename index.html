ScriptCraft — quick help

Writing

  • Enter starts the natural next line (scene → action, character → dialogue). Tab cycles line types; Shift+Enter adds a line break.
  • Autocomplete: start a scene heading and ScriptCraft offers INT./EXT., places you've already used, and DAY/NIGHT; on CHARACTER lines it offers existing names. Press Tab to accept, ↑↓ then Enter to choose, Esc to dismiss (tap a suggestion on a phone).
  • On a phone use the key bar above the keyboard: SCENE, ACTION, CHAR, PAREN, DIALOG, TRANS, ACT, TAG, NOTE.
  • Switch between Screenplay and Two-Column A/V at the top of the page. A/V: Ctrl+Enter adds a row.

Tagging (feeds the Production Inspector)

Select words and press TAG, or type [prop: x] [set: x] [wardrobe: x] [camera: x] [lens: x] [light: x] [gear: x] [note: x]. Tags and notes are removed from PDF and Fountain exports.

Production tools

  • File ▸ Production breakdown PDF lists every scene with its cast, props, wardrobe, camera, lighting and gear, plus master lists across the whole script.
  • File ▸ Call sheet PDF builds a one-day sheet from the scenes you put on that shoot day in the Schedule tab.
  • The Draft colour (top of the page) prints a revision label on every PDF page. View ▸ Analytics shows scene, cast, tag and schedule statistics.

More writing tools

  • Parentheticals get their brackets automatically. Dual dialogue: put the cursor on the second character's name and use Format ▸ Dual dialogue (or the DUAL key); the two speeches print side by side.
  • Find & replace: Ctrl+F. Undo / redo: Ctrl+Z / Ctrl+Y now also undo new lines and type changes.
  • Dashed lines on the page show where pages will break in the PDF. Switch them off in View ▸ Page breaks. File ▸ Paper size switches between A4 and Letter.
  • Draft colour: pick a colour before you edit. Lines you change or add after that are marked with * on screen and in the PDF. Switch back to White to clear the marks.
  • Outline tab: index cards with a summary per scene; reorder scenes with ↑ ↓. Version history keeps named copies you can compare and restore. Table read (Tools menu) reads the script aloud with a different voice per character.
  • Schedule tab: stripboard colours, auto-schedule by location, and a day-out-of-days chart. Storyboard tab: each panel can also hold shot size, movement and lens, and exports as a shot list PDF. Open file accepts Final Draft (.fdx) files.

Saving & offline

  • Everything auto-saves on this device and the app works with no internet once opened one time.
  • File ▸ Save file (Ctrl+S) writes a .scriptcraft project file you can back up, email or open on another device (File ▸ Open file).
  • ScriptCraft reminds you to save a backup file if it has been a week. File also lets you switch scene numbers and (CONT'D) on or off in the PDF.
  • Export PDF is built into the app — no internet needed. Accented letters outside basic Latin (for example ẹ, ọ, ṣ) print without their marks in the PDF; your saved file keeps them.
